# tpt-glyph-pdf-measure

Geometry and text-metric measurement over the TPT Glyph PDF IR: bounding boxes, path lengths, ink-coverage estimation, and font-based text metrics.

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Add it

`console
$ cargo add tpt-glyph-pdf-measure
`

See the crate documentation (cargo doc -p tpt-glyph-pdf-measure --open) for the public API and examples.
