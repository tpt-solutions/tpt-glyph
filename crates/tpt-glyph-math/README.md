# tpt-glyph-math

TeX-style math typesetting: a strongly-typed MathExpr AST, the TeXbook Ch.17 layout algorithm, and emission to tpt-glyph-core draw commands.

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Add it

`console
$ cargo add tpt-glyph-math
`

See the crate documentation (cargo doc -p tpt-glyph-math --open) for the public API and examples.
