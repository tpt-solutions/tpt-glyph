# out-glyph-diag

AI-assisted diagnostic tooling for TPT Glyph, built on the rendering knowledge graph.

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Usage

`console
$ cargo install out-glyph-diag
$ out-glyph-diag --help
`
