# tpt-glyph-font

Font metric parsing and glyph outlining for TTF/OTF via ttf-parser.

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Add it

`console
$ cargo add tpt-glyph-font
`

See the crate documentation (cargo doc -p tpt-glyph-font --open) for the public API and examples.
