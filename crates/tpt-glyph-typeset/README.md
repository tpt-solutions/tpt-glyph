# tpt-glyph-typeset

High-level document typesetting: paragraph layout, pagination, and page breaks, with inline tpt-glyph-math support, emitted as tpt-glyph-core draw commands.

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Add it

`console
$ cargo add tpt-glyph-typeset
`

See the crate documentation (cargo doc -p tpt-glyph-typeset --open) for the public API and examples.
