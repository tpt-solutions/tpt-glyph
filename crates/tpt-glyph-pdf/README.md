# tpt-glyph-pdf

PDF parsing and rendering for TPT Glyph, built on the pdf crate and the shared tpt-glyph-core pipeline.

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Add it

`console
$ cargo add tpt-glyph-pdf
`

See the crate documentation (cargo doc -p tpt-glyph-pdf --open) for the public API and examples.
