# tpt-glyph-pdf-parser

Robust PDF parsing into the canonical tpt-glyph-pdf-ir intermediate representation.

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Add it

`console
$ cargo add tpt-glyph-pdf-parser
`

See the crate documentation (cargo doc -p tpt-glyph-pdf-parser --open) for the public API and examples.
