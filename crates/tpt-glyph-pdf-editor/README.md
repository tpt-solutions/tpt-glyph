# tpt-glyph-pdf-editor

Transactional, functional-style editing of PDF documents: replace text, insert images, and save via tpt-glyph-pdf-writer.

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Add it

`console
$ cargo add tpt-glyph-pdf-editor
`

See the crate documentation (cargo doc -p tpt-glyph-pdf-editor --open) for the public API and examples.
