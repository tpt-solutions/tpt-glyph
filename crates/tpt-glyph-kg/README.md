# tpt-glyph-kg

Rendering Pipeline Knowledge Graph for TPT Glyph: operators, graphics state, and pixel-buffer effects.

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Add it

`console
$ cargo add tpt-glyph-kg
`

See the crate documentation (cargo doc -p tpt-glyph-kg --open) for the public API and examples.
