# tpt-glyph-pdf-ir

Canonical immutable intermediate representation of a PDF document.

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Add it

`console
$ cargo add tpt-glyph-pdf-ir
`

See the crate documentation (cargo doc -p tpt-glyph-pdf-ir --open) for the public API and examples.
