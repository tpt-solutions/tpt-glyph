# out-glyph-diff

Pixel-diff comparison harness: TPT Glyph output vs Ghostscript reference, with pass/fail thresholds.

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Usage

`console
$ cargo install out-glyph-diff
$ out-glyph-diff --help
`
