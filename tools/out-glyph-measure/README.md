# out-glyph-measure

Scaled line-measurement CLI: reports real-world lengths of PDF page geometry given a per-page drawing scale (e.g. 1:100, 1/4in=1ft).

Part of [TPT Glyph](https://github.com/tpt-solutions/tpt-glyph) — a secure, sandboxed, multi-threaded PDF/PostScript rendering engine (the Ghostscript successor).

## Usage

`console
$ cargo install out-glyph-measure
$ out-glyph-measure --help
`
